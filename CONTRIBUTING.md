# Contributing to Baccarat Predictor Pro

Thank you for your interest in contributing!

## Development Setup

1. Clone the repository
2. Follow the setup instructions in `docs/user-guide/installation.md`
3. Create a feature branch: `git checkout -b feature/your-feature-name`

## Code Style

- **Python**: Follow PEP 8, use Black for formatting
- **TypeScript**: Follow ESLint rules, use Prettier
- **Commits**: Use conventional commit messages

## Testing

- Write tests for all new features
- Ensure all tests pass: `pytest` (backend) and `npm test` (frontend)
- Maintain >80% code coverage

## Pull Request Process

1. Update PROGRESS.md if adding new features
2. Update documentation as needed
3. Ensure CI/CD passes
4. Request review from maintainers

## Questions?

Open an issue or contact the maintainers.
