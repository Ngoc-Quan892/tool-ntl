# Quick Start Guide

## First Steps

1. **Start the application** (see Installation Guide)

2. **Open the frontend**: http://localhost:5173

3. **Add your first result**:
   - Click "B" for Banker win
   - Click "P" for Player win
   - Click "T" for Tie

4. **View predictions**:
   - The prediction box shows the recommended bet
   - Confidence level indicates certainty
   - Pattern name shows detected pattern

5. **Explore roadmaps**:
   - Big Road shows main game flow
   - Derived roads show patterns

## Key Features

- **Real-time Updates**: Predictions update automatically
- **Statistics**: Track your session performance
- **Simulation**: Test strategies with 10,000+ shoes
- **Export**: Download data as CSV/JSON

## Tips

- Add at least 15 hands for accurate predictions
- Watch for high confidence alerts (>85%)
- Use roadmaps to identify patterns
- Run simulations to test strategies
