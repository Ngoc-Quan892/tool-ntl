# API Documentation

## Overview

The Baccarat Predictor Pro API provides endpoints for:

- Game result management
- Real-time predictions
- Roadmap generation
- Statistical analysis
- Simulation capabilities

## Base URL

- Development: `http://localhost:8000`
- Production: `https://api.baccarat-predictor.pro`

## API Versions

- **v1**: Legacy endpoints (maintained for compatibility)
- **v2**: Modern RESTful API with improved structure

## Authentication

Currently, the API is open. Future versions may require authentication.

## Rate Limiting

- 100 requests per minute per IP
- WebSocket connections: 10 per IP

## Documentation

- Interactive docs: `/docs` (Swagger UI)
- ReDoc: `/redoc`
- OpenAPI spec: `/openapi.json`

## Support

For API issues, open a GitHub issue or contact the maintainers.
